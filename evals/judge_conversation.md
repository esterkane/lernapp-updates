# Judge rubric for `conversation` tier German quality (used by validator tier as LLM-judge)
Score each exchange 0–2 on: Natürlichkeit, Register (B2–C1 Tutor, nicht umgangssprachlich),
grammatische Korrektheit, Korrekturqualität (verbesserte Formulierung + kurze Begründung),
Regelkonformität (keine TDN, keine erfundenen Prüfungsregeln). Report mean per dimension.
