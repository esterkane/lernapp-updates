# Blueprints (ADR-0005)

Static, hand-maintained exam parameters. **Never LLM-generated.** Initial values were seeded
from the research summary of testdaf.de; each file has `verified_on: null` until a human checks
it against the official page in `source_url` and sets the date.

Schema: see `.claude/skills/testdaf-blueprints/references/schema.md`.
`testdaf_paper/` is empty until the learner decides on the paper format (`/add-blueprint`).
